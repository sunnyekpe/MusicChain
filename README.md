# MusicChain

A decentralized music streaming platform for managing music collections with artist royalties on Stacks blockchain.

## Features

- Music track registration with metadata and genre classification
- Artist ownership verification and royalty management
- Streaming permissions and access control
- Instrument tagging for music discovery
- Decentralized music distribution platform

## Smart Contract Functions

### Public Functions
- `add-track` - Add new music track to platform
- `update-track` - Update existing track details
- `remove-track` - Remove track from platform
- `transfer-track` - Transfer track ownership to new musician

### Read-Only Functions
- `get-track-info` - Get track details and metadata
- `get-streaming-permission` - Check streaming access rights
- `get-total-tracks` - Get total tracks on platform
- `get-platform-stats` - Get platform statistics

## Usage

Deploy the contract to create a decentralized music streaming platform where musicians can upload their tracks and manage streaming rights while earning royalties.
